1. Visão do Produto 
Definição 
ConciliaAI é uma plataforma de inteligência fiscal que captura automaticamente XMLs fiscais (NF-
e, NFS -e, CT -e), classifica produtos e operações com regras parametrizadas auto -educativas, 
gera os blocos do SPED e prepara a empresa para a apuração de IBS e CBS da reforma tributária. 
Não é um ERP. Não é um sistema contábil. É uma ferramenta de inteligência de negócio fiscal 
que elimina a dependência de grandes sistemas para a geração do SPED. 
 
1.1 Problema que resolve 
• Escritórios contábeis pagam valores elevados por sistemas que fazem mais do que precisam 
e erram no básico 
• A classificação fiscal é refeita manualmente todo mês porque os cadastros não guardam o 
histórico de decisões 
• Nenhum sistema no mercado está posicionado para apuração de IBS/CBS da reforma 
tributária 
• Clientes de pequeno e médio porte (faturamento até R$ 1,5 milhão/mês) não têm ERP real 
— usam soluções fragmentadas 
 
1.2 Diferenciais competitivos 
Diferencial Descrição 
Cadastro auto-
educativo 
Fornecedor + NCM + CFOP + Estado = regra automática. Resolveu 
uma vez, não pergunta de novo no mês seguinte. O sistema aprende 
com cada decisão do contador. 
SPED independente Gera os blocos do SPED (0150, 0190, C100, D100 etc.) diretamente do 
XML processado, sem dependência de sistemas tradicionais. 
Posicionamento 
IBS/CBS 
Primeiro sistema posicionado para apuração dos novos tributos da 
reforma tributária. A estrutura é a mesma do PIS/COFINS, mas o 
posicionamento comercial é único no mercado.

2.2 Mecanismos de robustez 
Web Hook + Pooling (padrão de alta disponibilidade) 
Web Hook: agente que fica “escutando” a API de destino. Quando há dado novo, busca 
automaticamente. Pooling: fallback automático que se inicia caso o Web Hook falhe, garantindo 
que nenhuma informação seja perdida. Estrutura projetada para suportar mais de 1.000 acessos 
simultâneos sem degradação de performance.

4. Escopo do MVP — Produto Mínimo Vendável 
Critério de pronto 
O MVP está pronto quando um escritório contábil consegue, usando apenas o ConciliaAI: (1) 
cadastrar uma empresa com certificado A1, (2) capturar automaticamente os XMLs da SEFAZ, (3) 
classificar as operações com regras parametrizadas, (4) resolver divergên cias uma vez e nunca 
mais, (5) exportar os blocos do SPED prontos para validação. 
 
4.1 Funcionalidades do MVP 
# Funcionalidade Detalhamento 
01 Captura automática de XML 
via SEFAZ 
Certificado A1 da empresa + API SEFAZ. Busca 
automática de NF-e, NFS-e e CT-e emitidas e 
recebidas. Web Hook + Pooling como fallback. 
02 Importação manual de XML em 
bloco 
Upload de pasta com múltiplos XMLs de uma vez. 
Sistema verifica, parseia e cadastra automaticamente. 
03 Cadastro automático de 
clientes/fornecedores 
Extração do CNPJ do XML. Se não existe no cadastro, 
cria automaticamente com dados da Receita Federal. 
04 Cadastro inteligente de 
produtos por NCM 
Produto cadastrado com NCM vinculado ao CISC 
(atualização automática). Diferenciação por tipo de uso 
(revenda, consumo, matéria-prima). 
05 Motor de regras 
parametrizadas (inteligência 
de negócio) 
Variáveis: Fornecedor + NCM + CFOP + Estado de 
origem + Regime tributário. Satisfez as condições = 
lança automaticamente. Não satisfez = aponta 
divergência. Divergência resolvida = grava a solução 
para uso futuro. 
06 Geração dos blocos do SPED Blocos 0150, 0190, 0200, C100, C170, D100 etc. 
Exportação em TXT pronto para o Validador SPED. 
Inclui apuração de PIS/COFINS (e futuramente 
IBS/CBS). 
07 Gestão de divergências com 
alerta 
Dashboard com sinalização: OK, Atenção, Crítico. 
Indica exatamente onde está a divergência e o que 
precisa ser decidido. 
08 Assistente de IA (consulta à 
base) 
Consulta inteligente à base de dados: “Qual foi minha 
apuração do NCM X no período Y?”. Exporta resultado 
em Excel ou texto. 
09 White label Personalização de nome e logomarca por escritório 
contábil. Cada cliente vê o sistema como produto do 
seu contador. 
 
4.2 Fora do MVP (fases futuras) 
• Conciliação bancária e cartão corporativo (via Open Finance)

6. Fluxo Operacional do MVP 
O fluxo abaixo representa o ciclo completo de operação do ConciliaAI no dia a dia de um escritório 
contábil: 
Etapa Ação Detalhe 
1 Cadastro da 
empresa 
Contador cadastra CNPJ + filiais. Insere certificado A1. Sistema 
ativa Web Hook para SEFAZ. 
2 Captura automática Web Hook escuta a SEFAZ. Quando há XML novo (emitido ou 
recebido), busca automaticamente. Pooling como fallback. 
3 Parsing e cadastro Sistema parseia o XML, extrai CNPJ, NCM, CFOP, valores. 
Cadastra automaticamente fornecedor/cliente e produto se não 
existirem. 
4 Motor de regras Verifica: esse fornecedor + NCM + CFOP + estado já tem regra? 
SIM = lança automaticamente. NÃO = sinaliza como divergência. 
5 Resolução de 
divergências 
Contador resolve a divergência (ex.: esse papel alumínio é 
revenda, não consumo). Sistema grava a decisão. No mês 
seguinte, não pergunta de novo. 
6 Geração do SPED Exporta blocos do SPED em TXT: 0150, 0190, 0200, C100, 
C170, D100 etc. Pronto para validador. Inclui apuração 
PIS/COFINS (IBS/CBS futuro). 
7 Dashboard e IA Painel com status (OK, Atenção, Crítico). Assistente de IA para 
consultas à base: “Quanto comprei do NCM X?”, “Qual minha 
apuração no período Y?” 
 
6.1 Prazo estimado do MVP 
O MVP pode ser entregue em até 3 meses após o início do desenvolvimento. A entrega total do 
projeto (com todos os módulos e adaptações de uso) pode levar até 1 ano.
